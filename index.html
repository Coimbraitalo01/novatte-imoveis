Política de Privacidade - Novatte Imóveis
1. Coleta de Dados

Coletamos apenas os dados necessários para fornecer nossos serviços:

  • Dados de contato: nome, e-mail, telefone (opcional)
  • Preferências de busca: tipo de imóvel, localização, faixa de preço
  • Dados de navegação: cookies para melhorar a experiência do usuário
2. Finalidade do Tratamento

Utilizamos seus dados para:

  • Enviar oportunidades de imóveis que correspondam ao seu perfil
  • Melhorar nossa plataforma e serviços
  • Entrar em contato para esclarecer dúvidas sobre imóveis
3. Compartilhamento de Dados

Seus dados são compartilhados apenas com:

  • Corretores parceiros: quando você demonstra interesse em um imóvel específico
  • Prestadores de serviço: para envio de e-mails e análise de dados (sempre com contratos de proteção de dados)
  • Autoridades: quando exigido por lei

Não vendemos seus dados para terceiros.

4. Seus Direitos

De acordo com a LGPD, você tem direito a:

  • Acessar seus dados pessoais
  • Corrigir dados incompletos ou desatualizados
  • Excluir seus dados a qualquer momento
  • Revogar consentimentos anteriores
  • Solicitar portabilidade de dados

Para exercer seus direitos, entre em contato: novatteimoveis@gmail.com

5. Segurança

Implementamos medidas técnicas e organizacionais para proteger seus dados contra acesso não autorizado, alteração ou destruição.

6. Retenção de Dados

Mantemos seus dados apenas pelo tempo necessário para cumprir as finalidades descritas ou exigido por lei.

7. Cookies

Utilizamos cookies para:

  • Lembrar suas preferências de busca
  • Analisar o uso do site para melhorias

Você pode controlar cookies através das configurações do seu navegador.

8. Contato do Encarregado de Dados

Para questões sobre proteção de dados:

E-mail: novatteimoveis@gmail.com
